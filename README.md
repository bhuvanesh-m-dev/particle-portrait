# Particle Portrait

### Turn a face into a Three.js particle / line-art portrait

Particle Portrait is a Three.js-based creative graphics project that recreates a portrait using programmatically generated points, lines, coordinates, and WebGL rendering.

The project is designed to demonstrate how a portrait can be represented and rendered using code rather than simply displaying the original image as an image texture.

## 🧠 How It Works

Instead of simply displaying a portrait image, the project represents facial features using coordinates and geometric line paths.

The general pipeline is:

```text
Portrait
   ↓
Image / Line-Art Reference
   ↓
Feature Extraction
   ↓
Coordinate Generation
   ↓
Coordinate Normalization
   ↓
Three.js Geometry
   ↓
WebGL Rendering
   ↓
Particle / Line Portrait
```

The generated facial paths are converted into Three.js geometry and rendered using WebGL.

This makes it possible to manipulate the portrait programmatically, including its:

- Scale
- Position
- Opacity
- Geometry
- Line rendering
- Animation
- Camera
- Lighting / visual effects
